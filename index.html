Смотреть демо Разбор кейса

Задача

Агентству нужен был свой сайт с поиском пакетных туров, без выгрузки прайсов и без устаревших цен. Источник правды — базы туроператоров через Андромеду.

Стек
Next.js · Node proxy · Andromeda API
Роль
Frontend + интеграция API
Срок
~3 недели до продакшена
Контур
B2C + кабинет менеджера

Что сделано

  • Поиск — форма → GET_PRICE_FOR_AGENT / searchtour: страна, город вылета, даты, ночи, питание, звёздность.
  • Карточка тура — состав пакета, перелёты, допуслуги (виза / трансфер / экскурсия), пересчёт цены.
  • Бронирование — туристы + документы → заявка уходит в базу туроператора; статусы и документы тянутся через API.
  • Прокси-слой — ключи и подпись запросов на бэке, кэш справочников, нормализация ответов разных ТО в единый UI.

Результат

~2с средний ответ поиска
70+ туроператоров в выдаче
0 ручных выгрузок прайса

Как это работает

Цены не копируются в локальную БД — запрос идёт в живые базы ТО.

  1. 01 Сайт агентства

    Турист задаёт параметры поиска

  2. 02 Наш API-прокси

    Подпись, фильтры, единый формат ответа

  3. 03 Andromeda

    Маршрутизация к подключённым ТО

  4. 04 САМО-Тур / ТО

    Актуальная цена → бронь в базе оператора
