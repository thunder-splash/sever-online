Что под капотом

Фронт не знает ключей агента. Запрос уходит в наш прокси, тот подписывает вызов Andromeda и нормализует выдачу разных ТО в один формат карточки.

  • Поиск GET_PRICE_FOR_AGENT · STATEINC / TOWNFROMINC из справочников
  • Пакет перелёт, питание, допуслуги, пересчёт перед бронью
  • Бронь заявка в базе туроператора · статусы и документы по API
  • Стек Next.js · Node proxy · Andromeda API
