Как и обещал — кейс по САМО / Andromeda API.

**Что делал**
Онлайн-витрина турагентства: поиск пакетных туров и бронирование через Andromeda API (контур САМО). Цены не копируются в локальную БД — запрос уходит в живые базы туроператоров, бронь сохраняется у ТО.

**Покрытие**
• поиск (`GET_PRICE_FOR_AGENT` / searchtour) — страна, вылет, даты, ночи, туристы, фильтры  
• карточка пакета — перелёты, питание, допуслуги, пересчёт цены  
• бронирование → заявка в базе ТО, статусы и документы через API  
• прокси на бэке — ключи/подпись, нормализация ответов разных операторов в один UI

**Стек:** Next.js + Node proxy + Andromeda API  
**Срок:** ~3 недели до рабочего продакшена
