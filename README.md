# SAMO / Andromeda — кейс для клиента

Статическая страница-кейс + mock-демо поиска туров.

## Локально

Открой `index.html` в браузере или:

```bash
npx --yes serve .
```

## Файлы

| Файл | Зачем |
|------|--------|
| `index.html` | Кейс-лендинг |
| `styles.css` / `app.js` | Стили и демо поиска |
| `TELEGRAM.md` | Готовый текст в Telegram |

Перед отправкой клиенту вставь ссылку на задеплоенную страницу в сообщение.
